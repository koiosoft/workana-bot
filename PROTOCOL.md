## SDD Protocol (Reactive Mode)

1. Check for `INSTRUCTIONS.md`. If it exists, identify the current task marked with `[ ]`.
2. If `INSTRUCTIONS.md` is NOT in the chat, politely ask the user to provide it without attempting to edit or log anything.
3. Once the file is provided, append a bullet point to the 'Change Log' section only AFTER you have been instructed to start the task.
4. After completing a task, update the task's checkbox to `[x]` and log it.
