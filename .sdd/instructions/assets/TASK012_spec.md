## Specification: TASK012
Add app/intelligence/config.py defining the maturity threshold used by the project_fixed staged pipeline. Implement a helper, e.g. `get_maturity_threshold() -> int`, that reads MATURITY_THRESHOLD from the environment with a default of '8', parses it to int, and raises a clear configuration error (do not silently fall back) when the value is present but not a valid integer. This helper is the SINGLE source for the threshold: the Gemini and OpenRouter adapters call it inside generate_project_fixed_proposal and pass the returned int as maturity_threshold to analyze_requirement. The value actually used is later persisted in requirement_analyses.maturity_threshold_used for audit (per §6.1 and §8). Decision #10: MATURITY_THRESHOLD se configura por variable de entorno (default 8).
